수출입 품목 번호(HS코드)로 규제를 자동 분석하는 AI

K-BRIDGE

2025.08 ~ 2025.10 · 팀 4인 (기여 25%) · 요건 분석 · 요건-판례 교차 검증
#도메인적응력#무역행정자동화#CrossValidation#CoT
▶
◆ 문제

미국 소액면세 제도가 없어지면서 수출 셀러가 챙겨야 할 규제가 늘었습니다. 요건 하나만 틀려도 화물이 묶이는데, 언어 모델은 없는 규정도 그럴듯하게 만들어 냈습니다(환각). 그래서 성능보다 틀린 답을 걸러내는 게 먼저라고 봤습니다.

◆ 해결 방법
  • 요건을 4가지로 나눠 분석: 규제 · 절차 · 위험 · 사후 관리를 각각 따로 따져 봅니다.
  • 제가 맡은 부분 - 요건 분석과 교차 검증: 미국 공공 데이터 API(FDA·EPA 등)에서 요건을 가져오고, Tavily·SERP 검색은 공식 웹페이지로만 한정해 자료를 모았습니다. 이렇게 모은 요건을 팀원이 수집·분석한 미국 세관 판례와 교차 검증해 빠지거나 과한 항목을 표시하고 신뢰도 등급을 붙였고, 판매자가 필요하면 관세사에게 검토를 요청할 수 있게 했습니다.
◆ 주요 기능 상세 - 누르면 상세 보기 창이 뜹니다
★ 결과 - 만든 것

제 담당: 요건 분석(공공 데이터 API · 공식 웹페이지 한정 검색)과 요건-판례 교차 검증, 판정 신뢰도 등급.
팀 전체: 상품 등록부터 보고서까지 이어지는 흐름 6단계(LangGraph) · 요건 분석 단계 안에서 4가지 동시 분석(세부 규정·시험 절차·처벌·유효 기간)과 검증 3가지 · 미국 세관 판례를 모아 비슷한 사례 5건을 찾는 흐름(팀원 담당) · 최종 보고서 15개 항목 · 연동한 규제 기관 9곳 · 미국 품목 분류표 30,067건을 검색할 수 있게 정리.

팀 과제로 끝나서 실제로 얼마나 빨라졌는지는 재지 못했습니다.
