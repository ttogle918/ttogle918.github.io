서비스 지식베이스 10종

서비스마다 YAML 파일 하나에 키 종류·라벨·URL 패턴·검증 주소를 적는다. 파일을 추가하면 서버와 화면에 자동으로 반영된다. 10개 서비스에 키 종류는 모두 23개다. 원본은 backend/knowledge/*.yaml.

서비스 파일 판별 방식 검증 주소
AWS aws.yaml Access Key ID는 접두사(AKIA·ASIA) · Secret Key는 라벨 맥락 없음
Google Cloud gcp.yaml API 키(AIza) · OAuth ID · Secret(GOCSPX-) · 서비스계정 JSON은 라벨·URL 없음
GitHub github.yaml 접두사(ghp_ · github_pat_) + URL 있음
Kakao kakao.yaml REST·JS·Admin·Native 4종이 같은 32자라 라벨 맥락만 없음
Notion notion.yaml API 키(secret_ · ntn_) · Database/Page ID는 URL·라벨 · Data Source ID는 라벨 있음
Ollama ollama.yaml 접두사 없이 모양(32자 hex.24자)으로 없음
OpenAI openai.yaml 접두사(sk- · sk-proj-) · 조직 ID(org-) 있음
PostgreSQL postgresql.yaml 접속 문자열 postgres://user:pw@host (비밀번호가 있을 때만) 없음
Slack slack.yaml 접두사(xoxb- · xoxp-) 없음
Stripe stripe.yaml 접두사(sk_ · rk_ · pk_ + live/test) + URL 있음

Slack은 응답 본문을 봐야 성공 여부를 알 수 있어 검증 주소를 일부러 선언하지 않았다.
